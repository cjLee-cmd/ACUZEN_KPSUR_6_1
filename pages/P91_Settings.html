INFO API 키 발급 가이드
  1. Google AI Studio 웹사이트에 접속하세요
  2. 우측 상단의 "Get API Key" 버튼을 클릭하세요
  3. 프로젝트를 선택하거나 새로 생성하세요
  4. 생성된 API 키를 복사하여 위 입력란에 붙여넣으세요
  5. "연결 테스트" 버튼으로 키가 정상 작동하는지 확인하세요
  6. 테스트 성공 후 "저장" 버튼을 클릭하세요
[TIP] 무료 할당량: 분당 15회, 일일 1,500회 요청 가능
[!] 보안 주의사항
  • API 키는 브라우저의 localStorage에만 저장되며, 서버로 전송되지 않습니다
  • 공용 컴퓨터에서 사용 후에는 반드시 로그아웃하고 "삭제" 버튼을 눌러주세요
  • API 키를 다른 사람과 공유하지 마세요
  • 스크린샷이나 화면 공유 시 API 키가 노출되지 않도록 주의하세요
  • 사용량은 Google Cloud Console에서 모니터링할 수 있습니다
