# E2E 테스트 실행 Command

> **이 command는 E2E 테스트 실행 시 반드시 사용해야 합니다.**
> 사용자가 "E2E 테스트", "테스트 진행", "전체 테스트" 등을 요청하면 이 command를 실행하세요.

---

## 절대 규칙 (ABSOLUTE RULES)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  🚫 이 command 없이 E2E 테스트 직접 실행 금지                                │
│  🚫 사양 문서 읽기 전 브라우저 조작 금지                                     │
│  🚫 파일 수 미달 상태에서 진행 금지                                          │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## Step 1: 테스트 사양 문서 읽기 (필수)

**반드시 Read tool로 다음 파일을 먼저 읽을 것:**

```
03_Test/01_Context/TestSequence_Login_to_Stage3.md
```

이 문서의 다음 섹션을 반드시 확인:
- "🚨 AI/Claude 에이전트 필수 준수 사항" (lines 14-72)
- 필수 검증 체크리스트
- Step별 파일 목록

---

## Step 2: 파일 수 요구사항 확인

사양 문서에서 추출한 파일 수를 기록:

| Step | 필요 파일 수 | 폴더 경로 |
|------|-------------|----------|
| Step 1 (제품정보) | **8개** | `02_Step_1/` |
| Step 2 (임상자료) | **2개** | `03_Step_2/` |
| Step 3 (기타자료) | **16개** | `03_Step_3/` |
| Step 3 (LineListing) | **4개** | `01_PreProcessing_LineListing/` |
| **총합** | **30개** | |

```
⛔ 총 30개 미만 → 테스트 진행 금지
⛔ 각 Step 파일 수 미달 → 해당 Step 진행 금지
```

---

## Step 3: TodoWrite로 체크리스트 생성

테스트 시작 전 반드시 다음 항목을 TodoWrite에 추가:

```
□ 테스트 사양 문서 읽기 완료
□ Step 1: 8개 파일 업로드 확인
□ Step 2: 2개 파일 업로드 확인
□ Step 3: 20개 파일 업로드 확인 (16+4)
□ 총 30개 파일 확인 후 LLM 분류 시작
□ 마크다운 변환 결과 확인
□ 데이터 추출 완료 확인
□ PSUR 섹션 생성 확인
```

---

## Step 4: 테스트 실행

체크리스트의 각 단계에서:
1. **파일 수 확인** - UI에 표시된 파일 수 확인
2. **미달 시 즉시 중단** - 누락 파일 추가 업로드
3. **사용자에게 보고** - 현재 상태 명확히 전달

## 검증 실패 시 대응

```
파일 수 부족 발견 시:
1. ⛔ "LLM 분류 시작" 버튼 클릭하지 않음
2. 📋 누락된 파일 목록 사용자에게 보고
3. 📁 해당 Step으로 돌아가서 누락 파일 추가 업로드
4. ✅ 30개 확인 후에만 진행
```
