## 1. 로그인/계정

### Q1.1 로그인이 안 됩니다.
**A**:
1. 이메일과 비밀번호 정확히 입력했는지 확인
2. Caps Lock이 켜져 있지 않은지 확인
3. 브라우저 캐시 삭제 후 재시도
4. 다른 브라우저(Chrome 권장)로 시도

### Q1.2 비밀번호를 잊어버렸습니다.
**A**: 시스템 관리자(Master)에게 문의하여 비밀번호 재설정을 요청하세요.

### Q1.3 세션이 자동으로 끊깁니다.
**A**: 기본 세션 유지 시간은 24시간입니다. "로그인 상태 유지"를 체크하면 7일간 유지됩니다.

### Q1.4 다른 컴퓨터에서 동시 로그인이 가능한가요?
**A**: 예, 가능합니다. 단, 같은 보고서를 동시에 편집하면 충돌이 발생할 수 있습니다.

### Q1.5 계정을 새로 만들고 싶습니다.
**A**: Master 권한을 가진 관리자에게 계정 생성을 요청하세요.

## 2. 파일 업로드

### Q2.1 파일 업로드가 실패합니다.
**A**:
1. 파일 크기가 50MB 이하인지 확인
2. 지원되는 형식인지 확인 (PDF, DOCX, XLSX, TXT)
3. 네트워크 연결 상태 확인
4. 파일명에 특수문자가 있으면 제거

### Q2.2 .doc, .xls 파일이 업로드되지 않습니다.
**A**: 구버전 Office 형식은 지원되지 않습니다. .docx, .xlsx로 다시 저장하세요.
- Word: 파일 → 다른 이름으로 저장 → .docx 선택
- Excel: 파일 → 다른 이름으로 저장 → .xlsx 선택

### Q2.3 RAW ID가 잘못 분류되었습니다.
**A**: 해당 파일의 드롭다운 메뉴에서 올바른 RAW ID를 수동으로 선택하세요.

### Q2.4 같은 RAW ID로 여러 파일을 업로드할 수 있나요?
**A**: RAW5(안전성조치 메일), RAW7(안전성정보변경)은 복수 파일을 지원합니다. 다른 RAW ID는 1개만 가능합니다.

### Q2.5 업로드한 파일을 삭제하려면?
**A**: 파일 목록에서 해당 파일 우측의 **"X"** 버튼을 클릭하세요.

### Q2.6 스캔된 PDF도 처리되나요?
**A**: 스캔 PDF는 OCR 처리가 자동으로 수행되지만 텍스트 인식률이 낮을 수 있습니다. 가능하면 텍스트 기반 PDF를 사용하세요.

### Q2.7 암호화된 파일을 업로드할 수 있나요?
**A**: 아니요, 암호가 설정된 PDF/Excel/Word 파일은 처리할 수 없습니다. 암호를 해제한 후 업로드하세요.

## 3. LLM 처리

### Q3.1 LLM 처리가 오래 걸립니다.
**A**: 파일 수와 크기에 따라 15~30분 소요됩니다. 진행률 바를 확인하세요. 브라우저를 닫지 마세요.

### Q3.2 LLM 처리 중 오류가 발생했습니다.
**A**:
1. 네트워크 연결 확인
2. API 키가 올바르게 설정되었는지 확인 (설정 → API 키 관리)
3. API 할당량(쿼터)을 초과했는지 확인
4. 페이지 새로고침 후 재시도

### Q3.3 API 키가 설정되어 있지 않다고 나옵니다.
**A**: 설정 페이지에서 API 키를 입력하고 연결 테스트를 수행하세요.
- Gemini: [Google AI Studio](https://ai.google.dev/)에서 발급
- Claude: [Anthropic Console](https://console.anthropic.com/)에서 발급

### Q3.4 "할당량 초과" 오류가 발생합니다.
**A**: Gemini 무료 할당량: 분당 15회, 일일 1,500회입니다. 잠시 후 다시 시도하거나, 유료 플랜으로 업그레이드하세요.

### Q3.5 어떤 LLM 모델을 사용하나요?
**A**: 기본은 Google Gemini (gemini-3-flash-preview)입니다. 설정에서 Claude 또는 OpenAI로 변경 가능합니다.

## 4. 데이터 추출

### Q4.1 추출된 데이터가 비어 있습니다.
**A**:
1. 원본 파일에 해당 데이터가 있는지 확인
2. 마크다운 변환이 정상적으로 되었는지 확인
3. 파일 형식이 올바른지 확인 (RAW ID와 실제 내용 일치)

### Q4.2 데이터 충돌이 발생했습니다.
**A**: 동일한 변수가 여러 파일에서 추출된 경우입니다. 충돌 관리 패널에서 사용할 값을 선택하세요.

### Q4.3 CS/PH/Table이 무엇인가요?
**A**:
- **CS (Clinical Summary)**: 단일 값 데이터 (성분명, 허가일자 등)
- **PH (Phrase)**: 서술형 텍스트 (원시자료서술문 등)
- **Table**: 구조화된 표 데이터 (판매량 표, LineListing 등)

### Q4.4 추출된 데이터를 수정할 수 있나요?
**A**: 예, Stage 3 섹션 편집에서 해당 데이터가 사용된 부분을 직접 수정할 수 있습니다.

## 5. 섹션 편집

### Q5.1 섹션 내용이 로드되지 않습니다.
**A**:
1. Stage 2가 완료되었는지 확인
2. 브라우저 새로고침
3. 콘솔에서 오류 메시지 확인 (F12 → Console)

### Q5.2 AI 재생성 기능이 동작하지 않습니다.
**A**: API 키가 설정되어 있고 할당량이 남아 있는지 확인하세요.

### Q5.3 편집 내용이 저장되지 않습니다.
**A**:
1. 네트워크 연결 확인
2. 수동 저장 시도 (Ctrl+S 또는 저장 버튼)
3. 브라우저 localStorage 용량 확인

### Q5.4 다른 사용자와 동시 편집이 가능한가요?
**A**: 현재 버전에서는 동시 편집이 지원되지 않습니다. 한 사용자가 편집 중일 때 다른 사용자는 조회만 가능합니다.

### Q5.5 섹션 순서를 변경할 수 있나요?
**A**: PSUR 섹션 순서는 MFDS 규정에 따라 고정되어 있어 변경할 수 없습니다.

## 6. QC 검증

### Q6.1 QC 오류가 계속 발생합니다.
**A**: 오류 항목을 클릭하여 해당 섹션으로 이동하고, 문제를 수정한 후 "QC 재검증" 버튼을 클릭하세요.

### Q6.2 경고(WARNING)도 수정해야 하나요?
**A**: WARNING은 권장 사항으로 필수는 아닙니다. 단, FAIL 항목은 반드시 수정해야 합니다.

### Q6.3 QC 검증 기준은 무엇인가요?
**A**:
- 필수 데이터 누락 여부
- 날짜 형식 및 일관성
- 수치 일관성 (판매량, 환자 수)
- 섹션 완성도

### Q6.4 QC를 건너뛸 수 있나요?
**A**: Master 권한이 있는 경우 강제로 다음 단계로 이동할 수 있지만, 권장하지 않습니다.

## 7. 출력

### Q7.1 Word 문서 생성이 실패합니다.
**A**:
1. QC 검증이 통과되었는지 확인
2. 모든 섹션이 생성되었는지 확인
3. 브라우저 새로고침 후 재시도

### Q7.2 생성된 문서의 형식이 깨집니다.
**A**:
1. Microsoft Word로 열기 권장 (Google Docs에서는 일부 형식 깨질 수 있음)
2. 최신 버전의 Word 사용

### Q7.3 특정 섹션만 출력할 수 있나요?
**A**: 예, 출력 페이지에서 원하는 섹션을 선택하여 부분 출력이 가능합니다.

### Q7.4 출력 파일은 어디에 저장되나요?
**A**: 브라우저의 기본 다운로드 폴더에 저장됩니다.

## 8. 시스템/설정

### Q8.1 API 키를 어디서 발급받나요?
**A**:
- **Gemini**: [Google AI Studio](https://ai.google.dev/) → Get API Key
- **Claude**: [Anthropic Console](https://console.anthropic.com/) → API Keys
- **OpenAI**: [OpenAI Platform](https://platform.openai.com/) → API Keys

### Q8.2 API 키가 다른 컴퓨터에서 적용되지 않습니다.
**A**: API 키는 브라우저의 localStorage에 저장되므로 컴퓨터/브라우저마다 별도로 설정해야 합니다.

### Q8.3 시스템이 느립니다.
**A**:
1. 브라우저 캐시 삭제
2. 불필요한 탭 닫기
3. 네트워크 속도 확인
4. Chrome 사용 권장

### Q8.4 화면이 깨지거나 레이아웃이 이상합니다.
**A**:
1. 브라우저 확대/축소가 100%인지 확인 (Ctrl+0)
2. 브라우저 새로고침 (Ctrl+Shift+R)
3. 다른 브라우저로 시도

### Q8.5 오류 로그를 확인하려면?
**A**: 브라우저 개발자 도구(F12) → Console 탭에서 오류 메시지를 확인할 수 있습니다.

### Q8.6 데이터 백업은 어떻게 하나요?
**A**: 모든 데이터는 Supabase 클라우드에 자동 저장됩니다. 추가 백업이 필요한 경우 관리자에게 문의하세요.

## 문제 해결이 안 될 때

### 1. 기본 점검 사항
- [ ] 브라우저 새로고침 (Ctrl+Shift+R)
- [ ] 브라우저 캐시 삭제
- [ ] 다른 브라우저로 시도 (Chrome 권장)
- [ ] 네트워크 연결 확인

### 2. 지원 요청 시 포함할 정보
- 오류 발생 화면 스크린샷
- 브라우저 콘솔 오류 메시지 (F12 → Console)
- 사용 중인 브라우저 및 버전
- 발생 시간 및 작업 내용
