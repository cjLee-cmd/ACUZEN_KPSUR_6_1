## 1. 개요

### 1.1 Stage 2 파일 업로드란?
PSUR 보고서 생성에 필요한 소스 문서를 업로드하는 단계입니다.
- 총 **30개 파일**을 3단계에 걸쳐 업로드
- LLM이 자동으로 RAW ID 분류
- 분류된 파일은 마크다운으로 변환 후 데이터 추출

### 1.2 파일 업로드 흐름
```
파일 선택 → RAW ID 자동 분류 → 분류 확인/수정 → 다음 Step → LLM 처리
```

## 2. 지원 파일 형식

### 2.1 지원 형식

| 형식 | 확장자 | 최대 크기 | 주요 용도 |
|------|--------|----------|----------|
| PDF | .pdf | 50MB | 첨부문서, 용법용량, 효능효과 |
| Word | .docx | 30MB | 안전성조치, 임상노출데이터 |
| Excel | .xlsx | 30MB | 판매데이터, LineListing |
| Text | .txt | 10MB | 기타 텍스트 문서 |

### 2.2 지원되지 않는 형식
- .doc (구버전 Word) - .docx로 변환 필요
- .xls (구버전 Excel) - .xlsx로 변환 필요
- .ppt/.pptx (PowerPoint)
- 이미지 파일 (.jpg, .png 등)

### 2.3 파일명 권장 규칙
```
[RAW ID]_[문서유형]_[날짜/버전].확장자

예시:
RAW1.1_최신첨부문서_20260115.pdf
RAW3_시판후판매데이터_2025.xlsx
RAW12_국외신속보고_LineListing.xlsx
```

## 4. RAW ID 자동 분류

### 4.1 분류 원리
- LLM이 파일명과 내용을 분석하여 RAW ID 자동 할당
- 신뢰도 점수와 함께 결과 표시

### 4.2 분류 결과 화면
```
┌────────────────────────────────────────────────────────────┐
│ 파일명                      │ RAW ID          │ 신뢰도    │
├────────────────────────────────────────────────────────────┤
│ 최신첨부문서_아세트.pdf      │ RAW1.1 ▼        │ 95%  ✅  │
│ 용법용량_2026.pdf           │ RAW2.1 ▼        │ 92%  ✅  │
│ 판매데이터.xlsx             │ RAW3   ▼        │ 78%  ⚠️  │
│ 기타문서.docx               │ RAW7   ▼        │ 45%  ❌  │
└────────────────────────────────────────────────────────────┘
```

### 4.3 신뢰도 지표
| 신뢰도 | 아이콘 | 의미 | 조치 |
|--------|--------|------|------|
| 80% 이상 | ✅ | 높은 신뢰도 | 확인만 필요 |
| 50~79% | ⚠️ | 중간 신뢰도 | 검토 권장 |
| 50% 미만 | ❌ | 낮은 신뢰도 | 수동 확인 필수 |

### 4.4 수동 분류 변경
1. 해당 파일의 RAW ID 드롭다운 클릭
2. 올바른 RAW ID 선택
3. 변경사항 자동 저장

### 4.5 동일 RAW ID 복수 파일
일부 RAW ID는 복수 파일 가능:
- RAW5 (안전성조치 허가팀 메일) - 여러 개 가능
- RAW7 (안전성정보변경) - 여러 개 가능

## 5. 업로드 오류 해결

### 5.1 일반적인 오류

#### "파일 크기가 너무 큽니다"
- **원인**: 50MB 초과
- **해결**: 파일 분할 또는 압축

#### "지원하지 않는 파일 형식입니다"
- **원인**: .doc, .xls 등 구버전 형식
- **해결**: .docx, .xlsx로 다시 저장

#### "파일 업로드에 실패했습니다"
- **원인**: 네트워크 오류
- **해결**:
  1. 네트워크 연결 확인
  2. 페이지 새로고침
  3. 다시 업로드

### 5.2 RAW ID 분류 오류

#### "RAW ID를 할당할 수 없습니다"
- **원인**: 파일 내용 인식 실패
- **해결**: 드롭다운에서 수동으로 RAW ID 선택

#### 잘못된 RAW ID 자동 분류
- **원인**: 파일명이 모호하거나 내용 불분명
- **해결**: 드롭다운에서 올바른 RAW ID 수동 선택

### 5.3 파일 수 관련

#### "필수 파일이 누락되었습니다"
```
필수 파일 수:
- Step 1: 최소 8개
- Step 2: 최소 2개
- Step 3: 최소 20개
- 총합: 30개
```

**해결**: 누락된 파일을 추가 업로드

## 6. 자주 묻는 질문

### Q1. 같은 RAW ID로 여러 파일을 업로드할 수 있나요?
**A**: RAW5, RAW7 등 일부 RAW ID는 복수 파일을 지원합니다. 각 파일은 별도로 처리됩니다.

### Q2. 파일을 잘못 업로드했습니다. 삭제할 수 있나요?
**A**: 예, 파일 목록에서 해당 파일 우측의 **"X"** 버튼을 클릭하면 삭제됩니다.

### Q3. PDF가 스캔 이미지인 경우에도 처리되나요?
**A**: 스캔 PDF의 경우 OCR 처리가 자동으로 수행되지만, 텍스트 품질이 저하될 수 있습니다. 가능하면 텍스트 기반 PDF를 사용하세요.

### Q4. 업로드 중 브라우저를 닫으면 어떻게 되나요?
**A**: 업로드가 중단됩니다. 다시 접속하여 처음부터 업로드해야 합니다.

### Q5. 파일명에 한글을 사용해도 되나요?
**A**: 예, 한글 파일명을 지원합니다. 다만 RAW ID 분류 정확도를 위해 RAW ID를 파일명에 포함하는 것을 권장합니다.

### Q6. 암호화된 PDF/Excel을 업로드할 수 있나요?
**A**: 아니요, 암호가 설정된 파일은 처리할 수 없습니다. 암호를 해제한 후 업로드하세요.
