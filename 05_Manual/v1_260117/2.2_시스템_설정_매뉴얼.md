## 3. API 키 관리

### 3.1 Google Gemini API

#### API 키 발급
1. [Google AI Studio](https://ai.google.dev/) 접속
2. **"Get API Key"** 클릭
3. 프로젝트 선택 또는 생성
4. API 키 복사

#### 설정 방법
1. 설정 페이지 → **API 키 관리** 탭
2. **Google Gemini API Key** 입력란에 붙여넣기
3. **"연결 테스트"** 클릭
4. ✅ 성공 시 **"저장"** 클릭

#### 무료 할당량
| 항목 | 한도 |
|------|------|
| 분당 요청 | 15회 |
| 일일 요청 | 1,500회 |
| 토큰 한도 | 1M tokens/요청 |

### 3.2 Anthropic Claude API

#### API 키 발급
1. [Anthropic Console](https://console.anthropic.com/) 접속
2. 계정 생성 및 로그인
3. **API Keys** 메뉴
4. **"Create Key"** 클릭
5. API 키 복사

#### 설정 방법
1. 설정 페이지 → **API 키 관리** 탭
2. **Anthropic API Key** 입력란에 붙여넣기
3. **"연결 테스트"** 클릭
4. ✅ 성공 시 **"저장"** 클릭

#### 사용 가능 모델
- claude-opus-4-5 (최고 성능)
- claude-sonnet-4 (균형)
- claude-sonnet-3-5 (빠른 응답)

### 3.3 OpenAI API

#### API 키 발급
1. [OpenAI Platform](https://platform.openai.com/) 접속
2. 계정 생성 및 로그인
3. **API Keys** 메뉴
4. **"Create new secret key"** 클릭
5. API 키 복사

#### 설정 방법
1. 설정 페이지 → **API 키 관리** 탭
2. **OpenAI API Key** 입력란에 붙여넣기
3. **"연결 테스트"** 클릭
4. ✅ 성공 시 **"저장"** 클릭

### 3.4 API 키 저장 위치

API 키는 **브라우저 localStorage**에 저장됩니다.
```javascript
// 저장 키
GOOGLE_API_KEY      // Gemini
ANTHROPIC_API_KEY   // Claude
OPENAI_API_KEY      // OpenAI
```

> ⚠️ **주의**: API 키는 사용자별로 관리됩니다. 다른 컴퓨터에서 접속 시 재설정 필요.

## 4. LLM 모델 설정

### 4.1 기본 모델 선택

#### 사용 가능 모델

| Provider | 모델 | 컨텍스트 | 특징 |
|----------|------|---------|------|
| Gemini | gemini-3-flash-preview | 1M tokens | 기본값, 한국어 우수 |
| Gemini | gemini-2.5-pro-preview | 1M tokens | 고품질 |
| Claude | claude-sonnet-4 | 200K tokens | 균형 |
| Claude | claude-opus-4-5 | 200K tokens | 최고 품질 |
| OpenAI | gpt-4o | 128K tokens | 범용 |
| OpenAI | gpt-4o-mini | 128K tokens | 경제적 |

#### 단계별 모델 지정
| 단계 | 기본 모델 | 권장 |
|------|----------|------|
| 파일 분류 (classify) | gemini-3-flash-preview | Flash |
| 마크다운 변환 (convert) | gemini-3-flash-preview | Flash |
| 데이터 추출 (extract) | gemini-3-flash-preview | Flash |
| QC 검증 (qc) | gemini-3-flash-preview | Pro/Sonnet |

### 4.2 하이브리드 모드

#### 개념
저비용 모델로 초안 생성 → 고비용 모델로 정제
- **Draft**: Sonnet으로 초안 생성
- **Refine**: Opus로 품질 향상

#### 설정 방법
1. 설정 페이지 → **LLM 모델 설정** 탭
2. **"하이브리드 모드 사용"** 체크
3. Draft 모델 선택 (claude-sonnet-4)
4. Refine 모델 선택 (claude-opus-4-5)
5. **"저장"** 클릭

#### 비용 절감 효과
- 최대 **61% 비용 절감** (Opus 단독 대비)

### 4.3 토큰 한도 설정

| 설정 | 기본값 | 범위 |
|------|--------|------|
| 최대 입력 토큰 | 100,000 | 10,000 ~ 500,000 |
| 최대 출력 토큰 | 8,000 | 1,000 ~ 32,000 |
| 컨텍스트 사용률 경고 | 80% | 50% ~ 95% |

| 파라미터 | 기본값 | 설명 |

## 6. 보안 설정

### 6.1 세션 관리

| 파라미터 | 기본값 | 설명 |
|----------|--------|------|
| 세션 타임아웃 | 24시간 | 비활성 시 자동 로그아웃 |
| Remember Me 기간 | 7일 | 로그인 유지 기간 |

### 6.2 API 키 보안

- API 키는 **localStorage**에만 저장 (서버 전송 없음)
- 브라우저 개발자 도구에서 확인 가능하므로 주의
- 정기적인 키 갱신 권장

### 6.3 권한 검증

- 모든 페이지에서 역할 기반 접근 제어 (RBAC)
- 권한 없는 페이지 접근 시 자동 리다이렉트

## 자주 묻는 질문

### Q1. API 키 연결 테스트가 실패합니다.
**A**:
1. API 키가 올바르게 복사되었는지 확인
2. API 키 앞뒤 공백 확인
3. 해당 API 서비스의 할당량 확인

### Q2. 다른 컴퓨터에서 설정이 초기화되었습니다.
**A**: API 키는 브라우저별로 저장됩니다. 각 컴퓨터/브라우저에서 별도 설정 필요.

### Q3. 하이브리드 모드가 동작하지 않습니다.
**A**: Claude API 키가 설정되어 있는지 확인하세요. Gemini만 설정된 경우 하이브리드 모드 불가.
