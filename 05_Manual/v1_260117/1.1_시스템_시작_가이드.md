## 1. 시스템 소개

### 1.1 KPSUR AGENT란?

**KPSUR AGENT**는 **한국 제약 PSUR(정기안전성업데이트보고서) 자동화 시스템**입니다.

- 소스 문서에서 데이터를 자동 추출
- AI(LLM)를 활용한 보고서 섹션 자동 생성
- 식품의약품안전처(MFDS) 제출 규정 준수

### 1.2 주요 기능

| 기능 | 설명 |
|------|------|
| **파일 업로드** | PDF, Excel, Word 문서 업로드 |
| **자동 분류** | AI가 문서 유형 자동 분류 (RAW ID) |
| **데이터 추출** | CS/PH/Table 데이터 자동 추출 |
| **보고서 생성** | 15개 PSUR 섹션 자동 생성 |
| **QC 검증** | 품질 자동 검증 |
| **Word 출력** | 최종 문서 다운로드 |

### 1.3 지원 브라우저

| 브라우저 | 지원 |
|----------|------|
| Google Chrome | ✅ 권장 |
| Microsoft Edge | ✅ 지원 |
| Safari | ✅ 지원 |
| Firefox | ⚠️ 일부 기능 제한 |

## 2. 접속 방법

### 2.1 URL 접속

브라우저에서 아래 URL 접속:


## 3. 로그인

### 3.1 계정 정보 입력

1. **이메일** 입력
2. **비밀번호** 입력
3. (선택) **"로그인 상태 유지"** 체크
4. **"로그인"** 버튼 클릭

### 3.2 테스트 계정

| 역할 | 이메일 | 비밀번호 |
|------|--------|----------|
| Master | `main@main.com` | `1111` |
| Author | `author@kpsur.test` | `test1234` |
| Reviewer | `reviewer@kpsur.test` | `test1234` |
| Viewer | `viewer@kpsur.test` | `test1234` |

### 3.3 로그인 오류

| 오류 메시지 | 원인 | 해결 |
|------------|------|------|
| "이메일 또는 비밀번호가 올바르지 않습니다" | 잘못된 계정 정보 | 계정 정보 확인 |
| "네트워크 오류" | 인터넷 연결 문제 | 네트워크 확인 |
| "세션이 만료되었습니다" | 장시간 미사용 | 다시 로그인 |

```

│  [로고]              KPSUR AGENT              [사용자명] [로그아웃] │

│  ┌─────────┐                                                        │
│  │   📊    │  환영합니다, [사용자명]님!                              │
│  │ 대시보드│                                                        │
│  ├─────────┤  ┌──────────────────────────────────────────────┐      │
│  │   📄    │  │                                              │      │
│  │ 보고서  │  │     ➕ 새 보고서 생성                         │      │
│  │  목록   │  │                                              │      │
│  ├─────────┤  └──────────────────────────────────────────────┘      │
│  │   👥    │                                                        │
│  │  사용자 │  최근 보고서                                           │
│  │  관리   │  ┌────────────────────────────────────────────┐        │
│  │ (Master)│  │ 보고서명     │ 상태     │ 수정일           │        │
│  ├─────────┤  ├────────────────────────────────────────────┤        │
│  │   ⚙️    │  │ 타이레놀 PSUR│ Draft    │ 2026-01-15       │        │
│  │  설정   │  │ 아스피린...  │ InReview │ 2026-01-10       │        │
│  │ (Master)│  └────────────────────────────────────────────┘        │
│  └─────────┘                                                        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 4.2 주요 기능

| 버튼/메뉴 | 기능 | 권한 |
|----------|------|------|
| ➕ 새 보고서 생성 | 새 PSUR 보고서 시작 | Author+ |
| 📄 보고서 목록 | 전체 보고서 조회 | 전체 |
| 👥 사용자 관리 | 계정 관리 | Master |
| ⚙️ 설정 | 시스템 설정 | Master |

### 4.3 최근 보고서

- 최근 작업한 보고서 5개 표시
- 클릭 시 해당 보고서로 이동
- 상태: Draft → InReview → QC → Completed

## 5. 기본 네비게이션

### 5.1 좌측 메뉴

| 메뉴 | 설명 | 접근 권한 |
|------|------|----------|
| 대시보드 | 홈 화면 | 전체 |
| 보고서 목록 | 전체 보고서 | 전체 |
| 사용자 관리 | 계정 관리 | Master |
| 설정 | 시스템 설정 | Master |

### 5.2 상단 헤더

| 요소 | 설명 |
|------|------|
| 로고 | 클릭 시 대시보드 이동 |
| 사용자명 | 현재 로그인 사용자 |
| 로그아웃 | 세션 종료 |

### 5.3 작업 흐름 표시기

보고서 작성 중 상단에 표시:

```
[Stage 1] ──── [Stage 2] ──── [Stage 3] ──── [Stage 4] ──── [Stage 5]
  완료          진행중          대기          대기          대기
```

- 완료된 단계: 초록색
- 진행 중: 파란색
- 대기: 회색
- 클릭하여 해당 단계로 이동 가능

## 6. 역할별 안내

### 6.1 Master (시스템 관리자)

**권한**:
- 전체 시스템 접근
- 사용자 계정 관리
- 시스템 설정 변경

**첫 할 일**:
1. ⚙️ 설정 → API 키 설정
2. 👥 사용자 관리 → 계정 생성

**필독 매뉴얼**:
- [2.1 사용자 관리 매뉴얼](2.1_사용자_관리_매뉴얼.md)
- [2.2 시스템 설정 매뉴얼](2.2_시스템_설정_매뉴얼.md)

### 6.2 Author (보고서 작성자)

**권한**:
- 보고서 생성 및 편집
- 파일 업로드
- Word 출력

**첫 할 일**:
1. 대시보드 → **"새 보고서 생성"**
2. Stage 1~5 순서대로 진행

**필독 매뉴얼**:
- [1.2 보고서 작성 매뉴얼](1.2_보고서_작성_매뉴얼.md)
- [1.3 파일 업로드 가이드](1.3_파일_업로드_가이드.md)

### 6.3 Reviewer (검토자)

**권한**:
- 보고서 조회
- QC 검증 및 승인/반려
- 리뷰 코멘트

**첫 할 일**:
1. 보고서 목록 → "InReview" 상태 보고서 선택
2. Stage 4 (QC) 검토

**필독 매뉴얼**:
- [1.6 QC 검증 매뉴얼](1.6_QC_검증_매뉴얼.md)

### 6.4 Viewer (조회자)

**권한**:
- 읽기 전용

**첫 할 일**:
1. 보고서 목록에서 보고서 조회
2. 섹션 내용 확인 (편집 불가)

## 자주 묻는 질문

### Q1. 로그인이 안 됩니다.
**A**:
1. 이메일/비밀번호 확인
2. Caps Lock 확인
3. 브라우저 캐시 삭제 후 재시도

### Q2. 대시보드가 빈 화면입니다.
**A**:
1. 브라우저 새로고침 (F5 또는 Ctrl+R)
2. 다른 브라우저로 시도
3. 네트워크 연결 확인

### Q3. 메뉴가 일부 보이지 않습니다.
**A**: 역할에 따라 접근 가능한 메뉴가 다릅니다. Master만 설정, 사용자 관리에 접근 가능합니다.
