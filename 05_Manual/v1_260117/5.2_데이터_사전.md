## 1. 개요

### 1.1 데이터 유형

KPSUR AGENT에서 사용하는 데이터는 3가지 유형으로 분류됩니다.

| 유형 | 패턴 | 설명 | 예시 |
|------|------|------|------|
| **CS** | `CS{n}_{한글명}` | 단일 값 데이터 | CS0_성분명, CS5_국내허가일자 |
| **PH** | `PH{n}_{한글명}` | 서술형 텍스트 (문장/문단) | PH4_원시자료서술문, PH11_총괄평가문 |
| **Table** | `표{n}_{한글명}` | 구조화된 표 데이터 | 표2_연도별판매량, 표5_신속보고내역 |

### 1.2 데이터 소스 유형

| 소스 | 코드 | 설명 |
|------|------|------|
| **사용자 입력** | `user_input` | Stage 1에서 사용자가 직접 입력 |
| **RAW 데이터** | `raw_data` | 업로드된 문서에서 추출 |
| **계산값** | `calculated` | 다른 변수로부터 계산 |
| **생성값** | `generated` | LLM이 자동 생성 |

## 자주 묻는 질문

### Q1. 변수가 추출되지 않습니다.
**A**:
1. 올바른 RAW ID로 파일이 분류되었는지 확인
2. 원본 파일에 해당 데이터가 있는지 확인
3. 마크다운 변환이 정상적으로 완료되었는지 확인

### Q2. 계산 변수 값이 잘못되었습니다.
**A**: 의존 변수가 모두 추출되었는지 확인하세요. 계산 변수는 의존 변수가 모두 있어야 계산됩니다.

### Q3. 같은 변수가 여러 RAW에서 추출되었습니다.
**A**: 충돌 관리 패널에서 사용할 값을 선택하세요. 최신 문서의 값을 우선 선택하는 것을 권장합니다.
