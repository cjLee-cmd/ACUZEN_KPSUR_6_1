## 1. 개요

### 1.1 RAW ID란?
**RAW ID**는 PSUR 작성에 필요한 소스 문서의 유형을 식별하는 고유 코드입니다.
- 형식: `RAW` + 숫자 (예: RAW1.1, RAW3, RAW12)
- 총 17개 RAW ID 정의

### 1.2 RAW ID 분류 목적
- 문서 자동 분류 및 처리 자동화
- 적절한 PSUR 섹션에 데이터 연결
- 데이터 추출 로직 매핑

### 1.3 네이밍 규칙
| 범위 | 문서 유형 |
|------|----------|
| RAW1.x | 첨부문서 관련 |
| RAW2.x | 허가사항 개별 섹션 (용법용량, 효능효과, 주의사항) |
| RAW3~4 | 판매/허가 데이터 |
| RAW5~7 | 안전성 조치 관련 |
| RAW8 | 임상 노출 데이터 |
| RAW9 | 문헌 자료 |
| RAW12~17 | LineListing 및 특수 자료 |

- 컬럼 헤더 확인 (Excel)
- 문서 제목/헤더 확인 (Word, PDF)

## 6. 자주 혼동되는 RAW ID

### RAW1.1 vs RAW2.x
| | RAW1.1 | RAW2.x |
|---|--------|--------|
| 범위 | 첨부문서 전체 | 특정 섹션만 |
| 용도 | 전체 참조 | 세부 분석 |

**판단**: 문서가 전체 첨부문서면 RAW1.1, 특정 섹션만 발췌되었으면 RAW2.x

### RAW5 vs RAW6
| | RAW5 | RAW6 |
|---|------|------|
| 형태 | 개별 메일 | 취합본 |
| 파일 수 | 복수 | 단일 |

**판단**: 여러 건의 개별 파일이면 RAW5, 하나로 취합된 파일이면 RAW6

### RAW12 vs RAW13 vs RAW14 vs RAW15
| | RAW12 | RAW13 | RAW14 | RAW15 |
|---|-------|-------|-------|-------|
| 지역 | 국외 | 국내 | 전체 | - |
| 유형 | 신속 | 신속 | 원시 | 정기 |

**판단**: 국외 신속보고 → RAW12, 국내 신속보고 → RAW13, 원시자료 → RAW14, 정기보고 → RAW15
