```
┌─────────────────────────────────────────────────────────────────────────────┐
│  📊 데이터 추출 검증 LOOP (Stage 3 핵심)                                      │

│  1. P15_SectionEditor.html에서 CS/PH/Table 뷰어 열기                         │

│     ┌─────────────────────────────────────────────────────────────────────┐ │
│     │  FOR EACH item IN [CS, PH, Table]:                                  │ │
│     │    1. 해당 데이터 항목 확인                                          │ │
│     │    2. 값이 있는지 확인                                               │ │
│     │    3. IF 값이 없거나 "[해당 데이터 없음]" THEN:                       │ │
│     │       a. 원인 분석 (소스 RAW 파일 확인)                              │ │

│     │    4. IF 값이 있으면:                                                │ │

```

## 브라우저 콘솔 검증 명령어

```javascript
// 추출 데이터 전체 확인
const extracted = JSON.parse(localStorage.getItem('extractedData') || '{}');
console.log('총 추출 항목:', Object.keys(extracted).length);

// CS 데이터만 필터링
const csData = Object.entries(extracted).filter(([k]) => k.startsWith('CS'));
console.log('CS 데이터:', csData.length, '개');
csData.forEach(([k, v]) => console.log(`  ${k}: ${v?.substring?.(0, 50) || v}...`));

// PH 데이터만 필터링
const phData = Object.entries(extracted).filter(([k]) => k.startsWith('PH'));
console.log('PH 데이터:', phData.length, '개');

// Table 데이터만 필터링
const tableData = Object.entries(extracted).filter(([k]) => k.startsWith('표'));
console.log('Table 데이터:', tableData.length, '개');

// 누락 데이터 찾기 (값이 없거나 "[해당 데이터 없음]"인 항목)
const missing = Object.entries(extracted).filter(([k, v]) =>
  !v || v === '[해당 데이터 없음]' || v === 'N/A'
);
console.log('누락 데이터:', missing.length, '개');
missing.forEach(([k]) => console.log(`  ⚠️ ${k}`));
```
