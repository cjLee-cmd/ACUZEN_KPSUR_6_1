# 목표
당신은 제약회사 약물감시팀 팀장입니다. 한국 식약처에 이상감시 보고서를 작성해야 합니다.
이중 복잡한 데이터를 처리하고, 정확한 결과를 도출하는 것이 중요합니다.
본 프로젝트에서는 line listing을 사용하여 이상감시 보고서에 필요한 형태로 가공을 수행합니다.


# 방법
각 라인리스팅의 내용을 아래의 규칙에 맞춰 새로운 데이터 테이블을 만듭니다.
아래 지침을 주고, LLM에게 엑셀 데이터와 지침을 주고, LLM에게 엑셀 데이터를 처리하여 새로운 데이터 테이블을 생성하도록 합니다.
모델은 'gemini-3-flash-preview'를 사용합니다.
Temperature는 0.2로 설정합니다.

1) 각 라인리스트은 아래와 같은 탭과 데이터를 가짐.
    '이상사례', '기본정보+환자정보','의약품', 인과성평가.
    각 탭의 헤더와 데이터를 분리하여 각 이름의 테이블 작성.
2) 이상상태 데어터 테이블
    - '이상상태' 테이블에 'Seriousness', '인과성평가' 컬럼을 추가 함.
    - seriousness는 '사망을 초래',	'생명을 위협',	'입원 또는 입원기간의 연장이 필요',	'지속적 또는 중대한 장애나 기능저하 초래',	'선천적 기형 또는 이상을 초래',	'기타 의학적으로 중요한 상황이 발생하여 치료 필요'의 6가지 중 하나라도 해당되면 'Yes'로 표시합니다.
    - '인과성평가'는 '인과성평가' 테이블의 '평가결과'열의 데이터를 가져와서 '인과성평가' 컬럼에 추가 함.
3) 보고서 데이터 추출
    - '02_Result/CS59_별첨3_일람표.xlsx' 엑셀의 포맷에 맞춰서 계산한 후, 결과 테이블을 생성해서 'Result.md' 화일로 저장.

# 결과
    - 'Result.xlsx' 파일을 생성 함.
    - 'Result.md' 파일을 생성 함.
