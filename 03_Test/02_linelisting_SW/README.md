# Pharmacovigilance Data Processor (Test Software)

## 개요
이 프로그램은 이상감시 보고서 작성을 위해 Line Listing 데이터를 가공하는 웹 기반 도구입니다.
`instructions.md`의 요구사항에 따라 구현되었습니다.

## 기능
1. **엑셀 파일 업로드**: Line Listing 데이터가 포함된 `.xlsx` 파일을 업로드합니다.
2. **데이터 처리**:
   - '이상사례' 시트를 자동으로 인식합니다.
   - 6가지 중대성(Seriousness) 기준 컬럼을 검색합니다.
     - 사망을 초래
     - 생명을 위협
     - 입원 또는 입원기간의 연장이 필요
     - 지속적 또는 중대한 장애나 기능저하 초래
     - 선천적 기형 또는 이상을 초래
     - 기타 의학적으로 중요한 상황이 발생하여 치료 필요
   - 해당 기준 중 하나라도 'Yes', '1', 'Checked' 등으로 표시된 경우, 새로운 'Seriousness' 컬럼에 'Yes'를 추가합니다.
3. **결과 다운로드**: 처리가 완료된 데이터를 `Result.xlsx`로 다운로드합니다.

## 사용 방법
1. `index.html` 파일을 웹 브라우저(Chrome, Safari 등)에서 엽니다.
2. 화면의 "데이터 업로드" 영역을 클릭하거나 파일을 드래그하여 엑셀 파일을 업로드합니다.
3. "데이터 처리 및 Seriousness 평가" 버튼을 클릭합니다.
4. 미리보기 테이블에서 데이터가 올바르게 처리되었는지 확인합니다.
5. "결과 다운로드" 버튼을 클릭하여 `Result.xlsx` 파일을 저장합니다.

## 기술 스택
- **HTML5**: 구조
- **CSS3**: 스타일링 (Vanilla CSS)
- **JavaScript (ES6+)**: 로직
- **SheetJS (xlsx)**: 엑셀 파일 처리 라이브러리

## 주의사항
- 입력 엑셀 파일에 '이상사례' 시트가 반드시 존재해야 합니다.
- 중대성 기준 컬럼명이 요구사항의 문구를 포함해야 정확히 인식됩니다.
