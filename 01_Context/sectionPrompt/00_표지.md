# 00. 표지 섹션 프롬프트

{{COMMON_RULES}}

---

## 섹션 정보

- **섹션 ID**: 00
- **섹션명**: 표지
- **설명**: 보고서의 기본 정보를 포함한 표지 페이지

---

## 사용 변수

| 변수명 | 설명 | 데이터 소스 |
|--------|------|-------------|
| CS0_성분명 | 의약품 성분명 | 사용자입력 |
| CS1_브랜드명 | 의약품 브랜드명 | 사용자입력 |
| CS2_회사명 | 제약회사명 | 사용자입력 |
| CS3_보고시작날짜 | 보고기간 시작일 | CS4에서 5년 전 계산 |
| CS4_보고종료날짜 | 보고기간 종료일 | 사용자입력 |
| CS5_국내허가일자 | 최초 국내 허가일 | 사용자입력 |
| CS6_보고서제출일 | 식약처 제출일 | 사용자입력 |
| CS7_버전넘버 | 보고서 버전 번호 | 사용자입력 |
| CS8_버전날짜 | 버전 작성일 | CS4와 동일 |

---

## 템플릿

```markdown
# "[CS1_브랜드명]([CS0_성분명])"

**[CS2_회사명]㈜**

---

**보고기간:** [CS3_보고시작날짜] ~ [CS4_보고종료날짜]
**국내허가일자:** [CS5_국내허가일자]
**보고서제출일:** [CS6_보고서제출일]
**버전(작성일):** v.[CS7_버전넘버] ([CS8_버전날짜])

---
```

---

## 작성 지침

1. 모든 변수를 추출된 데이터로 치환한다
2. 날짜는 YYYY-MM-DD 형식으로 표시한다
3. 회사명 뒤에 '㈜'를 붙인다
4. 데이터가 없는 경우 `[해당 데이터 없음]`으로 표시한다
