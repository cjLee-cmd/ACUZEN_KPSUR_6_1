## 작성 지침

1. RAW7_안전성정보변경 데이터를 참조한다
2. 보고기간 동안 변경된 안전성 참고정보를 서술한다
3. 변경이 없는 경우 "본 보고기간 동안 안전성 정보 참고 정보의 변경은 없었다."로 작성한다
4. 상세 변경 내역은 별첨의 "허가사항 변경 전후 대비표"를 참조하도록 안내한다
5. **변경 이력은 반드시 번호별 하위섹션(`### 변경 이력 N:`) 구조로 작성한다**:
   - 각 변경 이력에 날짜 범위 표시 (변경 전 날짜 → 변경 후 날짜)
   - 효능효과, 용법용량, 사용상의주의사항 중 변경된 항목만 bullet point로 기술
   - 변경 내용은 구체적으로 기술 (예: "16세 이상 → 12세 이상으로 적용 연령 확대")
6. 변경 이력이 2건 이상인 경우 `### 변경 이력 2:`, `### 변경 이력 3:` 등으로 추가
7. 변경된 항목이 없는 경우 해당 항목은 생략 (예: 용법용량 변경 없으면 해당 bullet point 제외)
